# EventFlow

A local events sharing web app for Zimbabwe.
This was my very first full stack app using **Reactjs** and **Nodejs** with a **MongoDB** database in 2022.
The goal was to streamline local event and activity discovery within the country. 

It had a very basic UI, bugs, clunky navigation, but the funtionality was on point. Users could sign up, create and post events, filter events by category, date, price etc. 

Lessons from this attempt where so much more valuable than any course could buy, so it was not really a waste of time

It was a key learning project in fullstack development and as with learning projects, I can't even bear to look at the code 😔, but you are welcome to go through it, be prepared for disgust. There is no live website where a user can visit, only the _code_ exists.
